# 常名 Care-Engine 医疗场景模式匹配优先级

## 核心教训

**问题**：医疗场景对话中，模式匹配的**顺序**决定了回复质量。

**错误顺序**（后果）：
```
"术后要注意什么" → 匹配到"怎么办" → 回复"先不想那么远"
"手术做完了，今天出院" → 匹配到"手术" → 回复"担心是正常的，医生做过很多次"
```

**正确顺序**：
1. 具体医疗事件（胆囊/微创/全麻/麻醉/紧张）→ 最先匹配
2. 诊断/疼痛/化疗 → 其次
3. **术后/注意什么** → 在"怎么办"之前
4. **做完了/完成了/出院** → 在"手术"之前
5. 一般性手术 → 在后面
6. 康复/担心复发 → 再后面
7. 怎么办/该怎么办 → 靠后（兜底）
8. 家人/陪伴 → 最后

## 医疗场景扩展 checklist

添加新医疗场景关键词时，**必须**按优先级插入到正确位置：

- **阶段完成词**（做完了/出院/完成了）→ 必须在"手术/开刀"之前
- **具体感受**（术后/疼痛/难受）→ 必须在"怎么办"之前
- **具体治疗**（化疗/微创/全麻）→ 必须在一般性"手术"之前

## 验证方法

每加一个医疗关键词，必须跑完整对话流程：

```javascript
var conv = [
  '我要做胆囊手术了，好紧张',
  '今天手术要注意什么',
  '手术后第1天怎么过',
  '第2天能出院吗',
  '出院后饮食要注意什么',
  '什么时候能上班'
];
```

如果任何一句的回复逻辑不对（像在说"之前"的事），就说明顺序有冲突。
