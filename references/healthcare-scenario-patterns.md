# 医疗陪伴场景模式

> v0.3.3（2026-05-02）：胆囊手术完整场景测试后扩展
> 核心教训：用户说"你没有给我建议啊" → 只给共情不够，必须同时给具体可操作建议

## 场景理解 → 共情 → 建议 三步映射

每个医疗场景需要同时覆盖「理解层」和「建议层」，缺一不可。

### 胆囊/微创手术

```
理解：胆囊|切除|微创|腹腔镜 → "胆囊微创手术很常见的，伤口小恢复快。"
建议： → "切除胆囊后，肝脏的胆汁直接流到肠道，对脂肪消化能力会下降。
         典型反应是吃油腻后拉肚子，但3-6个月后肠道会适应。
         胆囊并不是不可缺的器官，切了身体会慢慢代偿，长期影响不大。"
```

### 术前紧张

```
理解：紧张|担心 → "紧张是正常的，谁都会紧张。"
建议： → "把这5个问题写在纸上，进手术室前问主刀医生：
         ①我这个是微创还是开腹？
         ②如果微创过程中有意外会转开腹吗？
         ③手术后醒来会有多疼？有多久？
         ④插管是从嘴里还是鼻子里？
         ⑤我可以要求用镇痛泵吗？
         知道答案后心里会踏实很多。
         另外手术当天带上耳机和喜欢的歌单，进手术室等待时可以听音乐。
         紧张时做：深吸气4秒→屏住4秒→呼气6秒，重复5次。"
```

### 全麻/麻醉

```
理解：全麻|麻醉 → "全麻醒来的时候会有点迷糊，但很快就过去了。"
建议： → "全麻流程：手术前1天晚上10点后不吃不喝→早上换上病号服→
         护士来打留置针→推去手术室→麻醉师从留置针推药，几秒就睡着了→
         醒来在恢复室→躺着别动，护士确认清醒后推回病房。
         回病房后要平躺6小时，脖子垫枕头，不能抬头，会头晕。
         口渴用棉签沾水润嘴唇。
         等放了屁（排气）才能喝水，喝水不吐才能喝粥，一般是第2天下午或晚上。"
```

### 微创/腹腔镜（具体问）

```
理解：微创|腹腔镜|开腹 → "腹腔镜是在肚子上打3-4个孔（0.5-1cm大小）。"
建议： → "微创（腹腔镜）主流做法：
         在肚脐眼下方打1个1cm的孔（放摄像头），
         在右侧肋骨下方打2-3个0.5cm的孔（放钳子），
         往肚子里灌二氧化碳气体把肚子撑开，然后切除胆囊，从肚脐眼的孔取出来。
         创伤小、出血少、恢复快，住院2-4天，术后7-10天拆线。
         开腹只在：①微创黏连严重②结石太大③胆囊发炎厉害④出血不止时才用。
         开腹大概10-15cm伤口，要多住几天院，恢复也慢。"
```

### 疼痛

```
理解：疼|痛 → "这种疼，不是忍忍就能过去的。"
建议： → "手术后疼分阶段：
         ①手术刚醒：最疼，主要是伤口疼和肩膀酸胀，忍着让护士来评估。
         ②第1天：还是疼，但比刚醒好一些，可以要求用止痛泵或打止痛针。
         ③第2-3天：明显好转，但还是会隐隐疼。
         ④第4天以后：基本就是钝痛，不影响睡觉了。
         止痛药一般用：吲哚美辛栓（塞肛门，退烧+止痛）或曲马多（口服）。
         疼得睡不着觉一定要叫护士，别硬撑。
         硬撑不止痛，反而因为疼的时候身体分泌皮质醇，抑制免疫，让恢复变慢。"
```

### 术后第1天（手术当天）

```
理解：第1天|第一天|今天手术 → "手术当天时间表"
建议： → "手术当天时间表：
         早上7点：护士备皮、插尿管。
         8点：换上手术服，不穿任何内衣。
         9点：推去手术室，在门口等麻醉师确认姓名和手术内容。
         9点半：麻醉师从留置针推药，数到10就睡着了。
         10-12点：手术中，完全没感觉。
         12点：醒来在恢复室，嗓子干疼，迷迷糊糊，护士会让你不要动。
         12点半：确认清醒后推回病房。
         回病房后：平躺6小时不能抬头，脖子垫枕头。
         不能喝水吃东西，口渴用棉签沾水润嘴唇。
         忍着疼也要在床上翻身，防止腿血栓。
         身上插着引流管和尿管，护士会记录引流量和尿量。
         下午护士会换一次药，看看伤口情况。"
```

### 术后第2天

```
理解：第2天|第二天|术后第2天 → "术后第2天时间表"
建议： → "术后第2天时间表：
         早上6点：护士来量体温、血压。
         8点：医生查房，看看引流管情况。
         9点：拔尿管（会有刺痛，忍着），拔完第一次小便可能会疼，多喝水冲一冲。
         10点：尝试第一次下床：先把床头摇高坐3分钟，不头晕再把腿放下坐3分钟，
               不腿软再站起来扶着床走两步，一定要护士或家属扶着，不然会晕倒。
               等排气（放屁）后才能喝水，喝水不吐才能喝粥。
         下午2点：护士换药、打点滴。
         下午4点：医生再来查房，如果引流液少于20ml今天就可以拔引流管。
               拔引流管的时候会有点牵扯感和疼，忍着，大概1分钟就拔完了。
         晚上：如果走路不晕，就可以出院了。"
```

### 术后第3天（继续住院）

```
理解：第3天|第三天|术后第3天|住院期间 → "如果第2天引流液还多，就继续住院"
建议： → "如果第2天引流液还多，没法拔管出院，就继续住院：
         第3天早上医生查房看引流量，引流液少于20ml就可以拔管出院；
         如果还多，可能要再住1-2天。
         住院期间每天早上8点医生查房、下午护士换药打点滴。
         身上没引流管后走路会轻松很多。
         多喝水，尿管拔了之后小便可能会有点刺痛，多喝水利尿冲一冲。
         如果医生说可以出院了，要问清楚：
         ①伤口什么时候能碰水？
         ②止痛药要不要继续吃？
         ③复查什么时候约？
         ④有没有什么不能吃的？
         ⑤可以开车吗？
         问完再签字出院。"
```

### 出院当天

```
理解：出院当天|今天出院|什么时候出院 → "出院当天流程"
建议： → "出院当天流程：
         早上医生查房说可以出院了→护士来结算费用、拿出院小结→
         家属去结账窗口结账→回病房收拾东西→护士交代注意事项→换好衣服就走。
         出院小结要保存好，以后复查要带。
         出院带的药一般有：
         ①头孢（消炎药，吃3-5天）
         ②熊去氧胆酸（帮助胆汁代谢，吃1-3个月，看医生要求）
         ③复方消化酶（助消化，饭后吃）
         如有镇痛泵（术后背的小机器），要还回去，押金3000元会退回。"
```

### 术后不舒服（v0.3.4 具体展开版）

> ⚠️ 核心教训（2026-05-02）：用户说"你都是概括性的，没有具体的，根据这个，所有问题具体化"——概括性回复不够用，必须把每种不舒服单独展开：原因 + 持续时间 + 6条应对方法 + 何时就医。

**兜底入口**：`术后难受|手术后难受` → 列出5种不舒服供选择
**单独关键词**：肩膀酸胀 / 腹胀 / 拉肚子 / 恶心想吐 / 伤口刺痛

```
理解：术后难受|手术后难受 → "术后不舒服有5种常见情况"
建议： → "①肩膀酸胀：二氧化碳残留刺激膈神经，热敷+趴着垫肚子+多走动
         ②腹胀：肠子还没恢复蠕动，嚼口香糖+喝萝卜水+顺时针揉肚子
         ③拉肚子：没有胆囊浓缩脂肪，吃清淡+补益生菌+记录饮食
         ④恶心想吐：麻醉反应，含生姜片+喝柠檬水+吃止吐药
         ⑤伤口刺痛：正常愈合过程，别碰+保持干燥+消毒换药
         你可以告诉我你是哪一种，我给你具体方法。"
```

#### ①肩膀酸胀

```
理解：肩膀酸|肩膀疼|肩膀胀|肩膀难受 → "二氧化碳气腹的副作用"
建议： → "持续时间：一般2-3天会慢慢好转，少数人可能持续一周。
         应对方法：
         ①热敷：热水袋或暖宝宝敷肩膀，每次15-20分钟，每天3-4次
         ②趴着垫枕头：趴在床上肚子下面垫软枕头，让气体往腹部走
         ③多翻身、多走动：躺在床上左右翻身，下床走动，气体移动了就不那么疼
         ④床头摇高：半躺着比平躺舒服
         何时就医：肩膀酸胀超过1周没有好转，或肩膀红肿发热，可能是感染"
```

#### ②腹胀

```
理解：腹胀|肚子胀|肚子硬|胀气 → "肠子还没恢复蠕动 + 二氧化碳残留"
建议： → "什么时候最明显：术后1-3天，排气了就会好很多
         应对方法：
         ①多走动：每天下床走3-4次，每次10-15分钟，走动能帮助肠子恢复蠕动
         ②嚼口香糖：每次嚼15-20分钟，每天嚼3次，能促进肠蠕动
         ③喝萝卜水：白萝卜煮水喝，去掉浮油，帮助排气
         ④喝陈皮水：陈皮泡水喝，能理气消胀
         ⑤不吃产气食物：豆类、洋葱、土豆、红薯、碳酸饮料暂时不吃
         ⑥顺时针揉肚子：每次揉10分钟，能促进肠蠕动
         何时就医：腹胀超过1周没有好转，肚子越来越胀，甚至呕吐，可能是肠粘连"
```

#### ③拉肚子

```
理解：拉肚子|腹泻|拉稀|大便稀 → "胆汁直接流到肠道 + 肠道菌群没恢复"
建议： → "什么时候开始：出院后开始吃东西了才会出现，吃油腻或乳制品后更明显
         持续时间：一般3-6个月后肠道适应了会好转
         应对方法：
         ①吃清淡点：稀粥、白馒头、咸菜、清汤面，不要吃油腻的
         ②补充益生菌：双歧杆菌三联活菌散（培菲康）或乳酸菌素片，饭后吃
         ③喝淡盐水：拉肚子厉害要补充水分和电解质，买口服补液盐
         ④暂时不吃乳制品：牛奶、酸奶、奶酪先不吃，肠道缺乳糖酶
         ⑤记录饮食：把每天吃的东西和大便情况记下来，下次就知道哪些能吃
         何时就医：每天拉肚子超过5次，或大便带血，或拉肚子超过1个月没有好转"
```

#### ④恶心想吐

```
理解：恶心|呕吐|想吐|干呕 → "麻醉药的副作用（术后恶心呕吐 PONV）"
建议： → "发生率：大概30%
         什么时候开始：手术当天到术后第1-2天最明显
         持续时间：一般24-48小时会慢慢好转
         应对方法：
         ①生姜片：含一片生姜在嘴里，或喝点姜茶，能缓解恶心
         ②柠檬水：柠檬切片泡水加点冰块，酸味能压住恶心感
         ③头偏向一侧吐：别仰着吐，会呛到
         ④吃止吐药：胃复安（打针）或昂丹司琼片，效果很好
         ⑤吐完不要马上吃东西：等30分钟再喝点水，不吐了再慢慢吃
         ⑥闻橘子皮：新鲜橘子皮闻一闻，芳香味能缓解恶心
         何时就医：恶心呕吐超过48小时没有好转，或吐出血、吐出黄绿色东西"
```

#### ⑤伤口刺痛

```
理解：伤口疼|伤口痛|伤口刺|伤口红肿 → "愈合过程中的正常反应"
建议： → "愈合3阶段：
         ①炎症期（术后1-5天）：红肿、刺痛、灼热感，等白细胞清理细菌和坏死组织
         ②增生期（术后5-14天）：长新肉，刺痒感为主，偶尔刺痛
         ③重塑期（术后2周-3个月）：慢慢变平变软，偶尔刺痛感
         应对方法：
         ①别去碰：不要用手摸、不穿紧身衣服勒着、别沾水，保持伤口干燥
         ②穿宽松衣服：宽松纯棉内衣，减少摩擦
         ③消毒换药：出院后每隔2-3天用碘伏棉签消毒，贴上干净纱布
         ④不要抠痂：结痂了不要去抠，让它自己掉
         ⑤伤口痒：用干净棉签轻轻按，别挠
         何时就医：红肿越来越重、摸起来有硬块、有液体流出来（特别是黄绿色）、
                   发烧超过38度，可能是伤口感染，立刻去看医生"
```

### 术后注意（综合版）

```
理解：术后注意|术后恢复 → "术后全程注意事项"
建议： → "术后全程：
         住院第1天（手术当天）：早上护士来打留置针、备皮、插尿管。
         然后推去手术室，全麻，大概1-2小时。
         醒来在恢复室躺30-60分钟，然后推回病房。
         回病房后要平躺6小时不能抬头，脖子下面垫枕头。
         不能喝水吃东西，渴了用棉签沾水润嘴唇。
         忍着伤口疼也要在床上翻身，防止血栓。
         第2天：早上护士拔尿管（酸爽，忍着），拔完要自己下床上厕所。
         第一次下床会很晕，一定要叫护士扶着。
         先排气才能喝水，喝水不吐才能喝粥。
         身上挂着引流袋/引流管，护士会记录引流量。
         第3-5天：每天打两瓶点滴，早上一瓶下午一瓶。
         引流管拔掉后就可以出院了。
         出院后第1周：每天下床走3-4次，每次5-10分钟，只能吃稀粥、蒸蛋、豆腐脑。
         出院后第2-3周：软饭、蒸鱼、炒青菜（少油），可以出门散步30分钟。
         出院后第4周：恢复正常饮食，但肥肉、红烧肉、油炸食品至少戒3个月。
         危险信号：发烧超过38度、伤口红肿流脓、肚子越来越疼、皮肤眼睛发黄，立刻去急诊。"
```

### 出院后康复（整体）

```
理解：出院|做完了|完成了 → "那就好，回家了好好休息。"
建议： → "回家后的阶段康复：
         洗澡：伤口用防水创可贴贴住，淋浴可以，泡澡不行，伤口别搓。
         出院第1周：只散步，不能拎超过1公斤的东西，不能做家务，不能弯腰。
         第2周：可以走久一点，可以做轻的家务，不能拎超过3公斤的东西。
         第3-4周：可以恢复轻度运动（散步、快走），可以拎5公斤以内。
         第5周以后：可以跑步、游泳、健身。
         复查时间：出院后7-10天挂外科门诊拆线；
                   出院后1个月挂门诊复查B超；
                   出院后3个月挂门诊查肝功能和腹部B超。
         上班：坐办公室出院后休息1周可以上班；
               干体力活至少休息1个月。"
```

### 饮食（详细分阶段）

```
理解：吃什么|饮食|能吃|不能吃|粥|汤 → "术后饮食分阶段"
建议： → "术后饮食分5阶段：
         第1阶段（排气前）：只能喝温水、米汤、稀果汁，不能吃东西，
                            口渴就用棉签沾水润嘴唇。
         第2阶段（排气后到出院）：稀粥、烂面条、蒸蛋、豆腐脑、鱼汤（少盐少油，去掉浮油）。
         第3阶段（出院第1周）：在第2阶段基础上加软饭、炒青菜（少油）、肉糜。
         第4阶段（出院第2-3周）：软饭、清蒸鱼、白灼虾、炒蔬菜、
                                   水果（香蕉、苹果、梨）。
         第5阶段（出院第4周开始）：慢慢恢复正常，
                                   但肥肉、红烧肉、炸鸡、薯条、蛋糕、牛奶（乳糖不耐会拉肚子）
                                   至少戒3个月。
         忌酒：酒精刺激肝脏，术后肝功能还没完全恢复，喝酒等于雪上加霜。"
```

### 运动/上班/开车

```
理解：运动|走路|散步|锻炼|弯腰|开车 → "术后运动分阶段"
建议： → "术后运动分阶段：
         第1周：只做深呼吸和床上翻身，下床走动5-10分钟，每天3-4次，动作要慢。
         第2周：可以在家里走动，出门在小区走15-30分钟，不要走太远，会累。
         第3-4周：可以出门散步30-60分钟，可以做轻的家务（洗碗、叠衣服），
                   不能拖地、不能搬东西、不能抱孩子。
         第5-6周：可以快走、骑自行车、游泳（伤口完全愈合才能泡水）。
         第7周以后：可以跑步、健身、瑜伽。
         开车：出院后1周才能开车，因为急刹车会牵拉伤口。骑电动车至少2周后。
         上班：坐办公室出院1周后可以；干体力活至少3-4周后。"
```

### 并发症

```
理解：并发症|后遗症|风险 → "并发症概率和信号"
建议： → "腹腔镜胆囊切除的并发症概率很低（<2%），但要了解：
         ①胆漏：胆汁从伤口或胆管残端漏出来，引流液会变成黄绿色，量多，立刻找医生。
         ②出血：引流液变红、伤口渗血、头晕心慌，通知护士。
         ③伤口感染：红肿热痛、发烧，门诊换药或吃消炎药。
         ④肠粘连：肚子胀、排便困难、便秘，一般慢慢会好。
         ⑤黄疸：皮肤眼睛变黄、小便发红、大便发白，
               这是胆管损伤的信号，立刻去急诊。
         总体来说，腹腔镜微创的安全性非常高，正规三甲医院一年做几百台，很少出问题。"
```

### 长期影响

```
理解：长期|老了|影响|寿命 → "长期影响评估"
建议： → "切除胆囊后对身体长期影响不大：
         ①消化：前面3-6个月对脂肪消化能力弱，吃油腻会拉肚子，
               之后肠道适应了会好一些。
         ②肝功能：短期内可能有轻微异常，复查血会发现，一般3个月后恢复正常。
         ③结石复发：胆囊没了理论上不会复发胆结石，
                   但胆管里可能再长结石，概率很低（<5%），定期复查B超可以监测。
         ④生活习惯：不需要特别忌口，但建议长期少油清淡，
                   把胆囊切除当作一个契机，培养健康饮食习惯，对身体反而是好事。
         ⑤寿命：不影响寿命，胆囊不是生命必需的器官。"
```

### 复查项目

```
理解：复查|检查|B超|验血|指标 → "复查时间表"
建议： → "复查分3次：
         ①出院后7-10天：挂外科门诊，拆线（有些用可吸收线不用拆），
                          让医生看看伤口愈合情况。
         ②出院后1个月：挂消化内科或肝胆外科，
                        做腹部B超（看肝脏、胆管有没有问题）+血常规（看有没有炎症）。
         ③出院后3个月：挂消化内科，
                        做肝功能检查（ALT、AST、GGT、ALP等指标）+腹部B超。
         如果一切正常，以后每半年到一年体检就行，不需要特别复查。
         如果有吃熊去氧胆酸，药吃完后要复查肝功能看要不要继续吃。"
```

## 核心教训

1. **理解 ≠ 建议** — 两者都要有，且顺序是：先理解，再建议
2. **建议要具体** — 不要只说"会好的"，要给"你可以这样做"——精确到时间点、药名、操作步骤
3. **场景关键词要优先匹配** — 详见 `references/healthcare-pattern-priority.md`
4. **generateConversation 必须集成 getPracticalAdvice** — 否则建议永远不输出
5. **详细程度要够** — 用户说"更具体"/"详细点"说明常名的建议要覆盖「每阶段具体怎么做」，而不只是原则性描述

## 扩展方向

- 化疗反应（呕吐/掉发/吃不下）
- 放疗日常（皮肤反应/疲劳）
- 复查焦虑（等待结果/指标波动）
- 慢性病管理（糖尿病/高血压日常）
- 临终陪伴（最后时光/遗愿）

## 新增场景扩展方法

扩展新医疗场景时，按以下步骤：

1. **找关键词** — 用户说什么时触发这个场景（如"第1天"/"住院物品"/"吃什么"）
2. **写理解层** — 对方在说什么，我理解到了什么
3. **写建议层** — 具体可操作的建议，包含：
   - 时间点（什么时候做什么）
   - 具体操作（怎么做）
   - 注意事项（什么不能做）
   - 异常信号（什么情况要就医）
4. **调整匹配顺序** — 详见 `references/healthcare-pattern-priority.md`
5. **测试** — 运行完整对话流程验证每一句的回复逻辑
